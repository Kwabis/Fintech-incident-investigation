# Evidence Plan

## 1. Authentication Logs

### Purpose
Determine whether suspicious or unauthorized access occurred.

### Evidence to Examine
- Login attempts
- Successful logins
- Failed logins
- Timestamps
- Source IP addresses
- Device information
- Authentication results

### Investigation Question
Was there suspicious access to the customer account before the unauthorized transaction?


## 2. Transaction Logs

### Purpose
Identify and analyze unauthorized financial activity.

### Evidence to Examine
- Transaction ID
- Timestamp
- Amount
- Sender account
- Recipient
- Transaction type
- Transaction status
- Associated IP/device where available

### Investigation Question
Which transactions were unauthorized, and what activity occurred immediately before them?


## 3. Account Activity Logs

### Purpose
Identify changes made to the customer account after suspicious access.

### Evidence to Examine
- Password changes
- Email changes
- Phone-number changes
- New device registration
- Security-setting changes

### Investigation Question
Were account settings modified after the suspected compromise?


## 4. Network/Security Logs

### Purpose
Determine whether network or security evidence supports the suspected compromise.

### Evidence to Examine
- Source IP addresses
- Destination information
- Connection timestamps
- Security alerts
- Suspicious network activity

### Investigation Question
Does the network/security evidence support the account-compromise hypothesis?
